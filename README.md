## Подготовка событий

Временные поля переводятся в datetime.

Для каждой cookie используются события из разрешённого окна

```python
event_ts >= window_start_ts
event_ts < window_end_ts
```

События после конца окна неизвестны в момент предсказания. Их использование создало бы утечку из будущего.

После фильтрации удаляются только полные дубли строк. События одной cookie с одинаковым временем сохраняются, если остальные поля различаются.

Платформы приводятся к единому виду

- desktop, WEB, Web и web объединяются в web
- ANDROID, Android и android объединяются в android
- ios, iOS, IOS и iphone объединяются в ios

После подготовки осталось 283 833 события. Было исключено 40 779 событий вне окна и 4 293 полных дубля внутри окна.

Исходные файлы не изменяются.

## Единица моделирования

Модель должна выдать один score для одной cookie. История событий агрегируется до одной строки на cookie через `groupby('cookie_id')`.

Общая таблица признаков строится для train и test одинаково. Target присоединяется только после построения признаков и только к train.

Такой порядок нужен по двум причинам

- код преобразований одинаков для train и test
- признаки не используют target

## Что показал EDA

### Интенсивность

Боты в среднем совершают больше событий. Распределения классов пересекаются, поэтому одного количества событий недостаточно.

Полезными оказались

- число событий
- число активных минут и часов
- длина активной части суток
- максимальное число событий за минуту
- число сессий

### Паузы

У ботов чаще встречаются короткие и более регулярные интервалы между действиями.

Используются

- медианная пауза
- квантили пауз
- стандартное отклонение
- межквартильный размах
- доля очень коротких пауз
- доля нулевых пауз
- медианная длительность сессии

Если у cookie одно событие, признаки интервалов остаются пропусками. Ноль здесь имел бы другой смысл.

### Действия

Для каждого типа события считаются количество и доля в истории.

В данные входят просмотры объявлений и поиска, контакты, избранное, просмотр продавца, листание фотографий и вход в аккаунт.

Количество описывает объём поведения. Доля описывает состав истории.

### Объявления и поиск

Поведение описывается не только количеством просмотренных объектов, но и повторяемостью интересов.

Используются

- число уникальных объявлений
- доля повторных просмотров
- число категорий и локаций
- концентрация на основной категории и локации
- доля профессиональных продавцов
- число поисковых запросов
- максимальная и средняя страница поиска
- доля глубоких поисков

### Возраст cookie

Возраст считается на момент окончания окна наблюдения.

```python
age_days = window_end_ts - cookie_created_at
```

Молодая cookie сама по себе не означает бота, но возраст дополняет остальные признаки.

### Координаты курсора

Самый сильный новый сигнал появился в координатах курсора.

На Android и iOS координаты отсутствуют. Сравнение проводилось внутри web, чтобы не смешивать различия платформ с различиями классов.

| Группа на web | Число кук | Известен разброс X | Медианный разброс X |
|---|---:|---:|---:|
| Люди | 4387 | 3028 | 553 |
| Боты | 486 | 205 | 202 |

Боты чаще не имеют координат или двигают курсор менее разнообразно.

Добавлены признаки

- число уникальных положений
- доля уникальных положений
- стандартное отклонение pointer_x
- стандартное отклонение pointer_y

### User-Agent

Полный User-Agent сохраняется как категориальный признак. Дополнительно выделяются семейство браузера и операционной системы.

Используются

- первый User-Agent cookie
- число User-Agent внутри окна
- семейство браузера
- семейство операционной системы
- число семейств браузеров и операционных систем
- наличие маркера автоматизации

Разбор выполняется фиксированными правилами и не использует target.

## Концентрация поведения

В расширенный вариант добавлены энтропии и повторяемость.

- энтропия действий
- энтропия объявлений
- энтропия категорий
- энтропия локаций
- энтропия запросов
- нормализованные энтропии
- доля повторных объявлений
- доля повторных запросов
- максимальная концентрация на одном значении

Энтропия измеряет разнообразие всей истории. Низкое значение соответствует концентрации на небольшом числе объектов или действий.

При исходных параметрах этот блок не улучшал технический вариант. Оба набора были проверены при одинаковом подборе параметров. После настройки CatBoost расширенный вариант дал лучший худший fold и был выбран.

Финальный набор содержит 84 признака

```text
56 baseline
9 новых технических признаков
19 признаков концентрации
```

## Временная валидация

Случайное разбиение не использовалось. Test находится позже train, поэтому локальная проверка тоже построена по времени.

| Разбиение | Обучение | Проверка |
|---|---|---|
| fold 1 | 6-9 апреля | 10-12 апреля |
| fold 2 | 6-12 апреля | 13-16 апреля |
| holdout | 6-16 апреля | 17-19 апреля |

Признаки и параметры выбирались только по fold 1 и fold 2. Holdout был открыт один раз после выбора модели.

Основной критерий выбора настроек

```text
максимальная метрика на худшем из двух fold
```

Так выбор меньше зависит от одного удачного временного периода.

Test не использовался для выбора признаков или параметров. На test проверялись только распределения и наличие новых категорий.

## Выбор модели

CatBoost выбран из-за сочетания числовых и категориальных признаков, пропусков и нелинейных зависимостей.

Логистическая регрессия использовалась как контрольная модель. Её лучший результат составил примерно 0,51 и 0,50 на двух fold. CatBoost лучше использовал совместные условия между платформой, координатами, паузами и интересами.

Проверялись

- глубины 5, 6 и 7
- learning rate 0,03 и 0,05
- веса положительного класса 1, 2 и 4
- random seed 17, 42 и 73
- усреднение трёх seed

Выбранная конфигурация

```python
CatBoostClassifier(
    iterations=243,
    depth=7,
    learning_rate=0.05,
    l2_leaf_reg=3,
    loss_function='Logloss',
    class_weights=[1, 1],
    random_seed=42
)
```

| Разбиение | Precision при Recall >= 0.70 |
|---|---:|
| fold 1 | 0,7477 |
| fold 2 | 0,6421 |

Дополнительный вес положительного класса не помог. Ансамбль трёх seed немного улучшил PR-AUC и Recall при FPR 0,01, но снизил основную метрику.

Медиана числа лучших итераций на двух fold равна 243. Это число используется при обучении без early stopping.

## Неопределённость оценки

Для предсказаний каждого fold выполнен стратифицированный bootstrap. Положительные и отрицательные объекты пересэмплировались раздельно.

| Разбиение | Метрика | 5 процентиль | Медиана | 95 процентиль |
|---|---:|---:|---:|---:|
| fold 1 | 0,7477 | 0,5648 | 0,7448 | 0,8342 |
| fold 2 | 0,6421 | 0,5070 | 0,6421 | 0,7160 |

Интервалы показывают, что локальная метрика чувствительна к составу выборки. Маленькую разницу между близкими настройками нельзя считать надёжным улучшением.

## Финальная локальная проверка

Holdout состоит из последних трёх дней train.

| Показатель | Значение |
|---|---:|
| Cookie | 1951 |
| Боты | 160 |
| Найдено ботов | 112 |
| Отмечено cookie | 154 |
| Precision при Recall >= 0.70 | 0,7273 |
| PR-AUC | 0,7611 |
| ROC-AUC | 0,9277 |
| Recall при FPR 0,01 | 0,5938 |

В лучшей допустимой точке recall равен 0,70.

```text
precision = 112 / 154 = 0,7273
recall = 112 / 160 = 0,70
```

Сравнение с baseline

| Модель | Holdout |
|---|---:|
| Baseline | 0,4766 |
| Улучшенная модель | 0,7273 |

Локальное улучшение равно 0,2507.

## Анализ ошибок

Во втором fold найденные боты имеют более высокий score, больше событий, меньшие паузы и большую глубину поиска.

Пропущенные боты ближе к людям

- медиана событий 13
- медианная пауза 45 секунд
- медианная глубина поиска 4
- медианный возраст cookie около 50 дней
- больший разброс курсора

Ложные срабатывания занимают промежуточное положение. Дальнейшее улучшение должно лучше описывать тихих ботов, а не только усиливать признаки высокой активности.

## Различия train и test

Для новых числовых признаков сравнивались медианы, пропуски и статистика Колмогорова-Смирнова.

Максимальная KS статистика равна примерно 0,046 для `pointer_x_std`. Разница долей пропусков меньше одного процентного пункта.

В test нет неизвестных значений для выбранных категориальных признаков

- platform
- browser_family
- os_family
- user_agent_first

Сильного сдвига в выбранных признаках не найдено.
